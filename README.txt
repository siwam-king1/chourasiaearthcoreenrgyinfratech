CHOURASIA EARTHCORE ENERGY INFRATECH - website

GitHub Pages par daalne ke steps:
1. github.com par new repo banao (naam: username.github.io  -> URL: https://username.github.io/ )
2. Is zip ki saari files (index.html, robots.txt) repo mein upload karo
3. Settings > Pages > Deploy from a branch > main > / (root) > Save
4. 1-2 minute baad site live: https://username.github.io/

Live hone ke baad:
- Google Business Profile > Website mein ye link daalo (end mein ?utm_source=google&utm_medium=organic)
- search.google.com/search-console par site add karo, verification tag index.html ke head mein
  "Google Search Console" wale comment ki jagah paste karo
- Search Console > URL Inspection > Request Indexing

Business number badalna ho to index.html mein PHONE='919378462324' search karke badlo.
